# UB_aulaSDR
Repository for the innovation on teaching project aulaSDR. 
The project is devoted to deploy SDR devices in classroms.
The main goal is:
"Expand and improve the set of significant educational experiences in radio communication systems currently found at the UB through the innovative digitalization of the classroom through the use of Software Defined Radio tools in theory classes for GEET, MEB and MESDM subjects."
